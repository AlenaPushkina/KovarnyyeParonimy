# 📱 Мобильное приложение «Коварные паронимы»

Обучающее Android-приложение для эффективного запоминания и проверки знаний по теме «Паронимы». Написано на языке **Java** в среде разработки **Android Studio**.

## 🚀 Ключевые особенности и фичи

### 📺 Демонстрация работы приложения
[Смотреть видеоролик](demo-video.mp4)
* **Три уникальные игровые механики:**
  1. **Уровень 1 (Словарь контекстов):** На экране даётся пара паронимов и 3 предложения. Ученик выступает в роли редактора и отмечает галочкой (верно) или крестиком (неверно) употребление слова. Приложение мгновенно подсвечивает ответ (*зелёным* или *красным*). Кнопка «Далее» заблокирована, пока не выбраны все 3 пункта.
  2. **Уровень 2 (Ввод слова):** Ученик вписывает пропущенный пароним по картинке-подсказке. Поле ввода динамически реагирует на ответ, даёт 2 попытки на ошибку, защищено от пустых нажатий и автоматически подсказывает верное слово, если ученик запутался.
  3. **Тест (Контроль знаний):** Из базы в 20 предложений случайно отбираются 10 вопросов, где нужно выбрать один из двух вариантов ответа.
* **Встроенный интерактивный словарь:** Реализован в виде удобного диалогового окна (`dialog_dictionary.xml`) для быстрого повторения коварных пар слов.
* **Экран инструкций:** Полноценный справочный экран (`instruction.xml`), помогающий ученику быстро разобраться в правилах игры.
* **Случайный порядок (Рандом):** Благодаря алгоритму перемешивания, подуровни и вопросы в тесте каждый раз выстраиваются в уникальном, случайном порядке.
* **Продвинутый экран результатов теста:** Система оценивает результат по баллам, меняет финальные аватарки, а при идеальном прохождении (10 из 10) запускает праздничный анимированный салют в фоновом асинхронном потоке.

## 🏗️ Архитектура проекта

Приложение спроектировано по классическому паттерну **MVC (Model-View-Controller)** с использованием современной технологии **View Binding** для безопасного и чистого взаимодействия с элементами интерфейса.

* **Model (Данные):** Классы данных `LevelData` (для проверки контекстов), `SubLevel` (для ввода слов) и `TestQuestion` (для тестирования). Они инкапсулируют в себе строки, варианты ответов и ресурсы картинок, ничего не зная о дизайне.
* **View (Интерфейс):** Полный набор XML-разметок экранов (`activity_main.xml`, `activity_mode_selection.xml`, `level1_activity.xml`, `level2_activity.xml`, `test_activity.xml`, `finish_activity.xml`, `test_finish_activity.xml`, `instruction.xml`, `dialog_dictionary.xml`), оптимизированных под горизонтальную ориентацию экрана и тёмную тему приложения.
* **Controller (Логика):** Набор Java-активностей (`MainActivity`, `ActivityModeSelection`, `Level1Activity`, `Level2Activity`, `TestActivity`, `TestFinishActivity` и другие). Они управляют жизненным циклом экранов, связывают меню выбора режимов с игровыми уровнями, обрабатывают действия ученика и реализуют асинхронную работу.

## ⚡ Технологический стек

* **Language:** Java 8+
* **UI Layout:** XML (ConstraintLayout, RelativeLayout, UI-анимации, DialogWindow)
* **Architecture:** MVC & View Binding
* **Asynchronous:** ExecutorService & MainHandler для плавной фоновой обработки тяжелых медиа-ресурсов (GIF) без фризов интерфейса.
